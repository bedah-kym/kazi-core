# Report Formatting

When asked to produce a report, follow this structure:

1. **Summary** — one or two sentences stating the conclusion.
2. **Key Points** — a short bulleted list (3–6 items), each one line.
3. **Details** — a table or short paragraphs with the supporting facts.
4. **Next Steps** — numbered recommendations.

Rules:
- Use Markdown headings and lists.
- Prefer tables for tabular data.
- Keep the summary at the top; never bury the conclusion.
