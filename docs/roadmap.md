# Roadmap

Here's where Kazi is, and where it's going — without the vaporware.

## Now: v0.4.2

Shipped and tagged. DeepSeek support (full tool-calling), a Telegram connector,
itinerary removal, the Skills system, and a hardening pass (output redaction,
JSON self-repair, context caps, auto-compaction).

## In flight: the v0.4 cycle

The v0.4 theme is *human-supervised runtime*. The milestone backlog lives in
[`v0.4-roadmap.md`](v0.4-roadmap.md) — each `M-x` heading is one GitHub issue,
with owners and acceptance criteria. No hidden backlog, no "coming soon" that
never comes.

## Why we publish it

Early access means breaking changes are possible before v1.0. The honest way to
handle that is to show you the plan and let you see what's real. If a milestone
stalls, the roadmap says so.
